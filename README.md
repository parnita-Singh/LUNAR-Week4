# Lunar Hollow: The Vanished Webmaster

A small mystery set on a fictional 2000s fan site.s Four guestbook suspects, a few clues, and a locked archive. Everything runs in the browser with no internet, no model, and no external assets.

## Run it

Open `index.html` in any browser. That's it.

## Files

- `index.html`: the site, including the guestbook, case file, and links
- `app.js`: clue logic, the notebook, and the archive password check

## How to play

1. Visit the Guestbook and click each suspect to question them.
2. Each answer adds a clue to the Notebook on the Case page.
3. Find the archive password from the clues (look at the page source too).
4. Unlock the archive to read Ren's final note.

## Why open tools

The whole game is plain HTML, CSS, and JavaScript. It runs offline, so there's no server to shut down. Anyone can read the source, change the clues, or build a new case without asking permission. A future version could use a local open-weight model (through Ollama) to rephrase clues in different voices, while the fixed answer stays in code so the game stays fair.
